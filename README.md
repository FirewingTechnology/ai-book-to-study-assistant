# AI Book-to-Study Assistant

A college/final-year project demo based on the uploaded project presentation. It turns uploaded text-based PDFs into topic-organized learning material: smart notes, important questions, easy explanations, MCQ practice, and video lesson scripts.

## Features

- React + Vite responsive learning interface
- FastAPI backend and SQLite database
- Student registration/login, JWT session, hashed passwords and student/admin roles
- Built-in Computer Networks demo book
- PDF upload, validation, and real text extraction for text-based PDFs
- Topic detection and topic-specific study material generation
- Optional real AI generation using an OpenAI API key, with labeled sample/fallback content if not configured or unavailable
- MCQ answer evaluation and persisted quiz history
- Saved materials, book library, and admin overview
- Sample student/admin accounts for local demonstrations

## Run locally

Requirements: Python 3.10+ and Node.js 18+.

### 1. Backend

```bash
cd backend
python -m venv .venv
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
# Optional: copy .env.example to .env and configure values in your environment
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API docs: http://127.0.0.1:8000/docs
Health check: http://127.0.0.1:8000/api/health

### 2. Frontend

Open another terminal:

```bash
cd frontend
npm install
# Copy .env.example to .env if your API URL differs
npm run dev
```

Open the Vite URL printed by the command (usually http://localhost:5173).

## Demo accounts

- Student: `student@example.com` / `Student123!`
- Admin: `admin@example.com` / `ChangeMe123!`

The backend seeds these demo accounts on first run. Change the admin password and set a long random `APP_SECRET_KEY` before any deployment accessible to others. Do not use these demo credentials for real user data.

## Optional real AI

Set `OPENAI_API_KEY` and optionally `OPENAI_MODEL` in the backend environment. Keep the API key only on the backend; never put it in a `VITE_*` variable or frontend code. If no key is configured or the model call fails, generated material falls back to a sample generator and the UI/API explicitly label that result as sample/fallback. This behavior is intended for dependable college demonstrations, not as a claim that the content was generated by an AI model.

## Hosting / deployment notes

This ZIP is a source project; it has not been deployed to a public URL. To host it online:

1. Deploy the FastAPI backend to a Python host with a persistent disk/volume.
2. Set `APP_SECRET_KEY`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `CORS_ORIGINS`, and optional `OPENAI_API_KEY`/`OPENAI_MODEL` on the backend service.
3. Deploy `frontend` as a static Vite site and set `VITE_API_URL` to the backend's HTTPS URL before building.
4. Ensure the hosting plan preserves `backend/data/study_assistant.db` and `backend/data/uploads` between restarts. Ephemeral filesystems will lose data.
5. Use HTTPS. For a real production service, consider managed PostgreSQL/object storage, rate limiting, account recovery, privacy/retention controls, and a hardened deployment configuration.

## Known limitations

- OCR for scanned/image-only PDFs is not included. If no extractable text is found, the app explicitly loads built-in Computer Networks sample text as a fallback.
- Upload limits: 15 MB and 300 pages. This is a demo limit, not a production capacity claim.
- Topic detection is heuristic; it works best on PDFs with headings and extractable text.
- Video Learning creates a script/storyboard only; it does not render an MP4.
- The language selector is passed to AI generation. Sample/fallback content is currently authored in English, so changing the language only affects generation when a real AI API is configured.
- The admin view is a read-only overview. It does not include user deletion or editing.
- SQLite/local uploads assume a single backend instance with persistent storage. Do not scale horizontally without moving state to shared services.
- The default dev secret and demo admin credentials are insecure for public hosting; override them before deployment.
